# Ozon Browser Shopper

Плагин для ChatGPT Work, который помогает выбирать товары на Ozon. Сначала он изучает подборки и сравнения моделей в интернете, затем проверяет предложения, цены и отзывы на Ozon. Если отзывов о точной модели там нет, ищет их на других маркетплейсах. При появлении капчи пользователь проходит её в том же браузере. Плагину не нужны MCP-сервер, парсер или ключи API.

## Установка

1. Скачайте репозиторий и в его корне создайте ZIP-архив с `plugin.json` и папкой `skills/`:

   ```sh
   zip -r ozon-browser-shopper-plugin.zip plugin.json skills
   ```

2. Откройте **Plugins** в ChatGPT на сайте, выберите **Add → Upload plugin** и загрузите `ozon-browser-shopper-plugin.zip`. Если пункта **Upload plugin** нет, для вашей учётной записи или рабочего пространства недоступна загрузка плагинов.
3. После установки откройте новый чат **Work** и вызовите `@ozon-browser-shopper`.

## Пример запроса

> @ozon-browser-shopper Подбери офисное кресло до 20 000 ₽ для ежедневной работы за компьютером в Москве. Нужна регулировка поясничной поддержки.
